# Card Builder App
The app Tabletop Simulator allows importation of a single image into a deck.  This tool is a very quick and dirty (zero art) way of transcribing text from a json into cards to import into TTS.  Good for prototyping.

Future version may incorporate art and finer tuned formatting per json file.  For now, it just takes the text and puts it on a card.

usage: CardBuilderApp.Exe -i input.json -o output.png
